CAMBIOS EN ACTIVIDAD BLUE-BOT

- Al completar correctamente un recorrido, se muestra un mensaje de felicitación.
- Después de la felicitación, el sistema avanza automáticamente al siguiente reto.
- Al completar el décimo reto, muestra una felicitación final y regresa a la selección de edades.
- El botón de ejecutar se reemplazó por un botón verde con el símbolo triangular ▶, sin texto, con etiqueta accesible y tooltip.
- No se modificaron los recorridos, niveles ni las reglas del juego principal.

Para verificar localmente: npm install && npm run build.
